# clerk概念模型

- 状态: 有效
- 用途: 判据表。系统实际长什么样，看`.clerk/workspace.toml`、种类声明与源码。
- 判定: 本文每一句，要么能落成`check`的一条规则，要么能决定一个文件放进哪个目录。两条都做不到的句子不进本文。

## 一、三条判据

新增任何文件、目录或命令前，先答三个问题。答不全就先改模型，再改实现。

| 问题 | 决定 |
|---|---|
| 它的身份是什么 | 键、路径，还是文件内的区块 |
| 谁能改它 | 用户、种类动词，还是渲染器 |
| 谁引用它 | 字段与状态、视图，还是没有引用方 |

## 二、六种形态

| 形态 | 身份 | 显示名 | 唯一性 | 存放 | 例子 |
|---|---|---|---|---|---|
| 取值域 domain | 首列，列名`key` | 必需`display` | 键唯一 | `config/registry/` | 状态、任务类型、仓库、前缀、来源 |
| 映射 mapping | 行首值 | 不要 | 整行不重复 | `config/registry/` | 别名到键、类别到目录 |
| 台账 ledger | 不声明 | 不要 | 整行不重复 | `config/registry/` | 账号归并、受限词与分类、当前批次 |
| 记录 record | 主键字段 | 字段自带 | 键唯一 | `data/` | 任务、资源、里程碑、验证、限制 |
| 文稿 document | 文件名 | 不适用 | 路径唯一 | 声明的目录 | 契约、复核、任务说明 |
| 页面 page | 文件加区块 | 不适用 | 不适用 | 声明的文件 | 现状页五个区块 |

归不进这六种的，说明设计与现实有差，改设计。

## 三、取值域

域是唯一要求显示名的形态，因为只有它被字段当作取值来源、被页面当作词表渲染。

| 规则 | 内容 |
|---|---|
| 一域一文件 | 文件名说明分类对象：`task_type.csv`、`limit_state.csv`；共用的用`state.csv` |
| 首列是键 | 域的首列叫`key`，键唯一 |
| 显示名按领域定语言 | 取值用中文，仓库与方向用英文标题 |
| 显示名不参与身份 | 只在渲染与`--display`输出里出现 |
| 多值归字段 | 多值由字段的`multi`决定，域不声明 |
| 不压缩多域 | 不把多套取值放进一张表，不设`axis:row`取法 |
| 不设旁路文件 | 显示名写在域文件里，不另建映射表 |

映射与台账只要求可读，不设显示名。别名是映射，把旧编号指向键。

## 四、一次写操作

提交说明属于基础层的Git收尾策略：显式说明优先，缺省按`required`、`auto`、
`default`策略处理。说明校验在业务写入之前完成；最终说明在接受本地数据之前写入
操作回执，重试只复用该说明。工作流各步骤共享一次提交说明。

```text
加锁并恢复中断操作 -> 检查已有封存 -> 取记录 -> 校验规则 -> 改数据 -> 重算封存 -> 接受本地修改 -> 自动提交与推送 -> 报告
```

页面由`render`从记录与域生成，使用同一写锁、撤销与Git收尾，不修改原始记录；用户手写正文不受影响。

写锁覆盖编号、读改写、封存和Git收尾。数据文件修改前将原内容写入本机撤销日志；
命令接受本地修改之前失败时恢复原文件，进程中断时由下次写命令恢复。批量导入与一批
请求共享同一撤销日志。只有带理由的`seal`允许接受已有封存漂移。

编号同时扫描在办与归档对象，并将已分配身份保存在封存目录的`issued.csv`中；删除和
归档不释放编号。升级前已经删除且没有历史记录的编号不能自动重建。

请求保存正文与执行选项。应用前检查基线与目标变化，以请求内容哈希去重；数据、请求
删除及回执属于同一次本地操作和Git提交。Git失败返回非零，保留已经接受的本地修改，
不把提交或推送失败伪装成数据回滚。工作区原本有未提交修改时仍按策略跳过自动提交。

撤销日志防护进程中断，不承诺断电持久性。只读命令和外部编辑器不参与写锁；跨克隆的
冲突仍由请求基线检查与Git合并处理。

## 五、不变量与检查

| 编号 | 不变量 | 检查输出 |
|---|---|---|
| I1 | 被枚举字段或状态引用的表是域，且有`display`；引用字段可引用词表首列 | `registry ... missing display column` |
| I2 | 域名等于文件名 | 加载失败 |
| I3 | 种类路径被某条`[[path]]`覆盖 | `path ... is not covered` |
| I4 | 数据目录里的表都被声明 | `data file has no declaration` |
| I5 | 别名指向存在的键 | `alias ... points at unknown key` |
| I6 | 显示名不参与身份解析 | 输入被拒 |
| I7 | 视图选项属于所用渲染器 | `view ... unknown key` |
| I8 | 命令、动词、选项及其默认值共用命令声明 | 未知选项与错误默认值在写入前被拒绝 |
| I9 | 引用字段声明唯一来源，每个非空值指向词表键或在办、归档对象的单字段主键 | 写入与`check`共用引用检查；未知或复合主键目标在加载时拒绝 |
| I10 | 创建期字段与工具字段的写入权限明确，文件名字段有输入或生成来源 | 创建、修改与请求共用权限检查 |
| I11 | 一批工作流共享本地事务，Git收尾不重放业务步骤 | 中途失败整批恢复，回执分别记录数据、提交与推送 |

Clerk运行元数据不属于共享业务资料，统一放在Git查询得到的元数据目录下的`clerk/`。
草稿、恢复回执、撤销日志、写锁和同步缓存按工作树隔离；活动会话放在公共Git目录的
`clerk/sessions/`，供同一仓库的多个工作树发现范围重叠。无Git工作区使用`.work/clerk/`。
操作回执和批处理步骤均只存本机，不生成受管回执文件。事务接受标记与完整本机回执
共同确定业务是否已接受；中断后先完成回执发布，再允许再次写入或重试Git。

终端文本的表格与键值块默认按显示宽度对齐，列之间留一个空格，中文按双列计算；多行值按续行对齐。
`--compact`省去列补齐空格，仍保留字段、顺序与完整内容。排版选项由共享命令元数据声明，
不改变JSON、CSV、TSV与Markdown的结构，也不改变受管文档渲染。
同级字段按列对齐，从属节点相对父级缩进两个空格；子级标签不续接父级的内容列。

上下文和模板的终端阅读输出按stdout可见窗口宽度主动换行，文件摘录显示源行号，
折行续行不重复编号。`--plain`保留原有层级和原文标记，关闭主动换行与行号；
管道和重定向缺省使用此模式。`--width`显式指定总列宽并启用阅读排版，与
`--plain`互斥；`--max-width`仍限制表格单元格。JSON和可执行模板预览不做阅读排版。

## 六、未决

上下文包属于记录的只读投影，来源字段在种类的`[context]`中声明；输出带原路径、
摘要与截断说明。读取与Clerk写入互斥，不执行恢复，也不抓取远端。
工作流模板属于行为层，身份为`config/workflows/`中的文件名，用户维护参数和步骤声明，
参数展开后交给同一个`batch`执行器。批次增删属于台账操作，在写锁内读取并修改集合。

| 事项 | 现状 |
|---|---|
| 附件 | 任务说明是文稿形状，由动作生成，未单独归类 |
| 日志 | 页面是`logs`种类，`add`动作追加、`prune`动作把旧页移入归档 |
| 域内顺序 | 页面顺序依赖行序，未声明排序字段 |
| 诊断输出 | `check`与`doctor`的 JSON 保留各自的嵌套结构，其余内建命令已用统一信封 |

## 七、协作登记与引用维护

日志的每个追加条目拥有独立身份，可通过动作声明的`entry_target`显式关联多个对象；
正文提及仅作为旧日志的补充检索。活动会话属于本机运行状态，按Git公共目录共享，
与任务负责人分离；路径范围重叠只提示协作风险，不能代替跨克隆的锁。

文件引用属于基础层：统一解析Markdown链接与正文中的独立路径，检查、扫描、修复
共用定位和解析。自动修复只接受Git重命名历史能够唯一证明且当前存在的目标，
不根据同名文件猜测。预览默认只读，确认应用后使用受管写入事务和Git收尾。

## 八、列表与身份约束

终端溢出属于展示层，不参与查询或业务写入。工具默认full，保持完整连续输出；truncate只显示一屏并明确提示完整读取入口；more在终端回滚中向下增量分页，pager按需交互分页，full连续输出。机器格式、管道和重定向保持完整，任何模式都不等待非交互输入。文档投影提供可重复表头与完整条目边界，通用展示层负责按终端高度截断或分页；调整窗口时重新渲染，退出不改变数据或命令结果。分页保留前后帧，只写入差异行，避免清空整屏造成闪烁。

任务列表属于视图投影：list与long分别声明适合比较的列、隐藏优先级和弹性列，不根据字段名称猜测长短。默认、long与显式columns共用终端宽度布局，每任务一行；弹性列优先获得剩余宽度，次要列按声明优先级隐藏，单元格过长省略。显式columns优先缩短单元格，只有最小列宽仍放不下时才隐藏列。details保留全部字段的竖排详情，完整值始终可读。表格多值以无空格逗号连接，机器输出保留原始值。

字段可声明`immutable = true`，创建后任何修改入口都不能改变其值，包括工具动作；自动时间值只在创建时初始化。发布者、发布邮箱和创建时间采用此规则。不可变约束保护后续写入，不追溯推断历史值。

本机operator保存在当前工作树Git元数据目录的`clerk/identity`；旧`layout.identity`只作为迁移来源，不再决定写入位置。Git账号、人员归并和本机operator保持独立，operator不决定任务归属。


## 九、共享匹配与终端发现

文字匹配属于基础层，literal和regex共用大小写策略与匹配位置；filter据此筛选记录，show和context据此解析只读候选，pager据此定位和高亮。写入与关系目标不使用近似选择。非法正则在读取遍历前拒绝，复杂度有上限。

终端策略属于展示层，模式和默认值由声明加载；paging控制自动或强制进入交互。语义样式与原始文字分离，宽度和搜索不读取ANSI码，颜色只在最终终端编码阶段应用，机器格式始终纯净。搜索位置独立于显示折行和颜色，缩放保留搜索状态。

Shell补全属于命令面，候选来自命令元数据、工作区声明与只读资料快照，不执行同步、恢复或写入。PowerShell脚本只传递当前上下文与展示候选，不复制合法参数清单。

上下文正文默认按字符数生成摘要，`context --full`取消附件、关联文稿与已选日志条目的正文长度上限，不改变一层关系与最近日志的选择范围。终端宽高策略独立于正文截断；机器输出采用相同正文选择，不添加ANSI颜色。

折行后的生成栏与逻辑正文分别承载样式，普通输出、pager与more复用同一套样式映射。原文内的冒号不参与工具元数据识别，行号与续行分隔栏统一弱化；上下文字段复用声明样式，来源、截断与诊断由生成者显式赋予角色。

## 十、源码与文档归属

读取选项按数据范围、查询排序、正文、展示、阅读和写入治理分组。适用入口、枚举候选与约束集中于命令元数据，帮助、校验、补全和机器声明复用。短名只服务手工输入，由同一份选项声明维护且全局唯一；输出格式保留长名，Agent、脚本与持久示例使用完整命令、动词、选项和枚举值。CLI枚举可使用唯一前缀，持久声明只接受完整值。命令面统一解析长选项的空格与等号写法、短选项的组合与紧连值，以及结束选项标记。短选项组遇到有值选项后将余部作为值，枚举先精确匹配再解析唯一前缀；固定候选与声明的枚举字段共用解析规则。简写仅用于CLI显式参数，进入批处理草稿和请求前转为完整值，配置、文件输入及过滤表达式保留精确语义。`data-scope`统一当前、归档与全量读取，替代`archived`；来源属于查询元信息，不进入业务字段。

帮助属于命令面的结构化只读投影，选项名、短名、参数占位、说明、候选与默认值分别保存，不解析展示标签恢复语义。展示层按整页计算选项列宽，窗口变动后从页面重新排版；窄屏采用上下布局，不截断内容。总览只承担分组导航与通用入口，具体命令提供适用选项及上下文说明，帮助、补全和校验复用适用规则。

pager只接收读取投影提供的可选排序能力，不排序显示文字，不重新读取业务文件；重排完整快照后重建匹配并尽量保留记录位置。搜索与排序共用字素编辑器，搜索只读取原始逻辑文字，颜色与搜索强调在最终编码时组合。输入光标与视口位置独立，取消恢复已确认状态；浏览时Enter继续搜索，编辑时Enter确认。

文档按用途分为`guide/`、`features/`、`maintenance/`与`architecture/`，文件名不带顺序编码。
文档入口是[文档导航](../README.md)，使用手册保留完整阅读路线，专题页承担详细规则。
迁移与历史复核保留验证时的边界，不把历史结论当作当前功能说明。

源码按职责声明真实Rust模块，不通过路径属性或旧路径别名掩盖归属；入口只负责启动。
目录表示维护职责，不表示已经消除了所有跨目录依赖；既有调用方向与运行行为保持不变。

| 目录 | 职责 |
|---|---|
| `foundation/` | CSV、错误、时间与版本 |
| `config/` | 声明解释、种类、词表、工作区与身份 |
| `storage/` | 表与文稿、编号、归档记录与封存 |
| `execution/` | 上下文、操作执行、事务、校验与渲染 |
| `collaboration/` | 关注事项、接手资料、日志、会话、请求、引用与模板 |
| `git/` | 审计钩子、同步、提交说明与操作回执恢复 |
| `query/` | 匹配、过滤、排序与只读编号选择 |
| `terminal/` | 值显示、文本布局、输出、分页、搜索与样式 |
| `interface/` | 命令解析、分发、帮助、输入与补全 |
| `bin/` | 附属二进制入口 |

新增文件先按职责定位，测试模块跟随所属实现，端到端测试仍放在`tests/`。

通用否定参数`--no/-N`属于命令面，候选来自当前命令适用且声明了否定行为的选项，
共用枚举的完整值优先和唯一前缀规则。否定行为分为显式关闭值与取消默认选择；
取消默认选择会屏蔽命令配置回填，并保留工具与种类的基础行为，不改工作区配置。
正向与否定输入按出现顺序覆盖，进入执行、请求或草稿前转为规范值与默认屏蔽标记。
帮助、补全和机器声明复用否定声明，不能关闭的参数不参与候选。

帮助的无表头多列内容按各列显示宽度对齐，末列使用剩余宽度；窄屏时说明相对条目
缩进两个空格，不借用内容列表达从属关系。pager搜索编辑时Esc取消本次编辑，浏览时
Esc先清除搜索并保留视口，无搜索时Esc退出；q在输入框内保持普通字符。
